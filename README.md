## 📌 প্রজেক্ট ওভারভিউ (Project Overview)

এই সফটওয়্যারটি কওমি মাদ্রাসা, আলিয়া মাদ্রাসা, হিফজখানা, নূরানি একাডেমি ও লিল্লাহ এতিমখানার অভ্যন্তরীণ সকল একাডেমিক, ফিন্যান্সিয়াল ও প্রশাসনিক কার্যক্রম সম্পূর্ণ ডিজিটালাইজ করার জন্য নির্মিত।

- **উচ্চ গতি (Offline-First 60 FPS):** সম্পূর্ণ লোকাল সিস্টেমে রকেট গতিতে রান হয়, কোনো ইন্টারনেট সংযোগ ছাড়াও নির্বিঘ্নে চলবে।
- **জিরো-লিক প্রাইভেসি বাউন্ডারি (Zero-Leak Privacy):** প্রতিটি সংবেদনশীল এপিআই মাস্টার পিন ছাড়া সম্পূর্ণ লকড।
- **স্টিলথ অ্যাডমিন মোড (Stealth Admin Access):** সাধারণ ভিজিটরদের চোখে অ্যাডমিন প্যানেলের কোনো লিঙ্ক বা বাটন দেখা যাবে না; মালিক ও পরিচালকের জন্য গোপন কিবোর্ড শর্টকাট ও লিংক সক্রিয়।
- **সিনেমাটিক ৩.৮ সেকেন্ড মোশন ইন্ট্রো:** স্প্রিং ফিজিক্স, সার্কিট লাইন স্ক্যান ও গোল্ডেন শিমার ইফেক্টসহ বিশ্বমানের লোডিং পর্দা।

## 🥷 স্টিলথ অ্যাডমিন এক্সেস (Stealth Admin Access)

পাবলিক ওয়েবসাইট থেকে অ্যাডমিন প্যানেল সম্পূর্ণ লুকানো থাকে। শুধুমাত্র অনুমোদিত কর্তৃপক্ষ নিম্নোক্ত ৩টি উপায়ে প্রবেশ করতে পারবেন:

1. **গোপন লিংক:** ব্রাউজারে `http://localhost:3000/admin` বা `http://localhost:3000/#admin` এ যান।
2. **কিবোর্ড শর্টকাট:** কীবোর্ডে একসাথে চাপুন <kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>A</kbd> (অথবা <kbd>Alt</kbd> + <kbd>A</kbd>)।
3. **ফুটার ট্রিপল ট্যাপ:** ওয়েবসাইটের নিচে **"© ২০২৬ Hedayet Tech"** লেখার ওপর দ্রুত ৩ বার ক্লিক করুন।

> 🔑 **ডিফল্ট মাস্টার পিন (Default Master PIN):** `2026` (ড্যাশবোর্ডের সিস্টেম সেটিংস থেকে পরিবর্তনযোগ্য)।

## 💻 ইনস্টলেশন ও রান করার নিয়ম (Installation Guide)

### ১. রিপোজিটরি ক্লোন করুন
```bash
git clone https://github.com/karvionlabs/madrasa-management-system.git
cd madrasa-management-system
```

### ২. ডিপেন্ডেন্সি ইন্সটল করুন
```bash
npm install
```

### ৩. সার্ভার চালু করুন
```bash
node server.js
```

### ৪. ব্রাউজারে ওপেন করুন
- **পাবলিক পোর্টাল:** [http://localhost:3000](http://localhost:3000)
- **স্টিলথ অ্যাডমিন গেটওয়ে:** [http://localhost:3000/admin](http://localhost:3000/admin) (পিন: `2026`)

## 🛡️ সাইবার সিকিউরিটি ও ডাটাবেস প্রোটেকশন
- **SQL Injection:** ১০০% প্যারামিটারাইজড স্টেটমেন্ট (`better-sqlite3`)।
- **Stored XSS:** সম্পূর্ণ ফ্রন্টএন্ড DOM স্যানিটাইজেশন (`escapeHtml`)।
- **Rate Limiting:** গ্লোবাল এপিআই ও লিড স্প্যাম প্রতিরোধ মিডলওয়্যার।
- **Helmet Security Headers:** OWASP নির্দেশিত ফ্রেমগার্ড, স্নফিং ও ক্যাশ প্রিভেনশন পলিসি।
- **Database Backup:** সিক্রেট ভল্ট কি ছাড়া ডাটাবেস ডাউনলোড সম্পূর্ণ নিষিদ্ধ (`HTTP 403 Forbidden`)।
